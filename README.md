## 📋 О проекте

SafeNet — это веб-приложение-тренажёр, созданное для обучения основам кибербезопасности через интерактивные задания и игровые механики. Платформа помогает пользователям научиться распознавать фишинг, вредоносные сайты, мошеннические письма и защищать свои персональные данные.

### Почему SafeNet?

- 📈 **Актуальность**: Ущерб от IT-преступлений в России за 7 месяцев 2025 года составил 119,6 млрд рублей (+16%)
- 🎮 **Геймификация**: Обучение через практику, а не скучную теорию
- 🎯 **Практические навыки**: Симуляция реальных киберугроз
- 📱 **Доступность**: Адаптивный интерфейс для всех устройств

## ✨ Основные возможности

- 🔐 **Регистрация и авторизация** пользователей

- 🏆 **Геймификация**: баллы, рейтинги, уровни

### Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Dev-PGVAA/Safe-Net.git
cd Safe-Net
```

2. Установите зависимости:

```bash
npm install
```

3. Настройте переменные окружения:

```bash
cp .env
```

Отредактируйте `.env`:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/safenet"
NEXTAUTH_SECRET="your-secret-key"
NEXTAUTH_URL="http://localhost:3000"
```

1. Примените миграции базы данных:

```bash
npx prisma migrate dev
```

5. Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🎮 Основной функционал

### Типы заданий

1. **Распознавание фишинговых писем** — анализ подозрительных email-сообщений
2. **Проверка сайтов** — определение поддельных и мошеннических веб-страниц
3. **Безопасность паролей** — создание надёжных паролей
4. **Защита персональных данных** — правила безопасного поведения в сети
5. **Распознавание вредоносных программ** — идентификация потенциальных угроз

### Система прогресса

- ⭐ Накопление баллов за правильные ответы
- 📊 Отслеживание статистики обучения
- 🏅 Разблокировка новых уровней
- 🎯 Достижения и награды
- 📈 Глобальный рейтинг пользователей
