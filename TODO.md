## Seed данных (`prisma/seed.ts`)

### Структура seed скрипта

- [ ] **Этапы и курсы:**
  - создать 3-5 этапов (Beginner, Intermediate, Advanced...)
  - для каждого этапа создать 5-10 курсов
- [ ] **Уроки (~300 шт):**
  - для каждого курса создать 10-20 уроков
  - генерировать реалистичный `content` (markdown с примерами кода)
  - установить правильный `order` для последовательности
- [ ] **Задачи (`Task` + `TaskOption`):**
  - к каждому уроку создать 3-7 задач разных типов
  - для каждой задачи создать 2-5 вариантов ответа
  - пометить правильные ответы (`isCorrect: true`)
- [ ] **Тесты (несколько десятков):**
  - привязать тесты к курсам
  - для каждого теста создать 5-15 `TestQuestion`
  - к каждому вопросу добавить 3-5 вариантов ответа
  - установить `correctAnswers` для проверки
- [ ] **Тестовые пользователи:**
  - создать админа
  - создать 10-20 обычных пользователей
  - для некоторых пользователей создать `UserCourse` с прогрессом
  - добавить `TaskAttempt` для реалистичной статистики
- [ ] **Запуск:**
  - настроить `package.json`: `"prisma": { "seed": "ts-node prisma/seed.ts" }`
  - запуск через `npx prisma db seed`

## Маршруты (сводка)

### Пользовательские

- `/dashboard` — главная
- `/dashboard/learning/courses` — список курсов
- `/dashboard/learning/courses/:slug` — страница курса
- `/dashboard/learning/lessons/:id` — страница урока
- `/dashboard/learning/practice` — практика
- `/dashboard/learning/tests` — список тестов
- `/dashboard/learning/tests/:id` — прохождение теста
- `/dashboard/learning/tests/:id/result` — результат теста
- `/dashboard/certificates` — мои сертификаты
- `/dashboard/certificates/:id` — просмотр сертификата

### Админские

- `/dashboard/admin` — главная админки
- `/dashboard/admin/stats/overview` — статистика
- `/dashboard/admin/stats/courses` — аналитика курсов
- `/dashboard/admin/learning/courses` — управление курсами
- `/dashboard/admin/learning/courses/:id/edit` — редактирование курса
- `/dashboard/admin/learning/lessons/:id/edit` — редактирование урока
- `/dashboard/admin/learning/tests` — управление тестами
- `/dashboard/admin/learning/tests/:id/edit` — редактирование теста
- `/dashboard/admin/users` — список пользователей
- `/dashboard/admin/users/:id` — карточка пользователя
